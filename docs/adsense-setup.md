## 申请条件

### 基本要求

在申请 AdSense 之前，网站需要满足以下条件：

| 条件 | 要求 | 当前状态 |
|------|------|----------|
| 网站内容 | 原创、有价值的内容 | ✅ 已满足 |
| 网站运营时间 | 建议至少 1-3 个月 | ⏳ 需要时间积累 |
| 流量要求 | 建议日 PV 500+ | ⏳ 需要流量积累 |
| 内容数量 | 至少 20-30 个页面 | ✅ 已满足 |
| 政策合规 | 无违规内容 | ✅ 已满足 |
| 域名 | 独立域名（非子域名） | ⚠️ 如使用 Vercel 域名，建议绑定自定义域名 |

### 重要提示

⚠️ **新网站建议先运营 1-2 个月，积累一定流量后再申请 AdSense**

原因：
- Google 需要时间评估网站质量
- 有流量的网站更容易通过审核
- 新网站可能被认为"内容不足"

## 申请流程

### 步骤 1：准备网站

1. **绑定自定义域名**（推荐）
   - Vercel 默认域名：`xxx.vercel.app`
   - 建议绑定独立域名，如：`aitools.yourdomain.com`
   - 独立域名更显专业，审核通过率更高

2. **确保内容完整**
   - 添加"关于我们"页面
   - 添加"隐私政策"页面
   - 添加"联系我们"页面
   - 确保所有链接可用

3. **检查移动端适配**
   - 网站需要支持移动端访问
   - 响应式设计已实现 ✅

### 步骤 2：申请 AdSense 账号

1. 访问 [Google AdSense 官网](https://www.google.com/adsense/)
2. 点击"开始使用"
3. 登录 Google 账号（建议使用企业邮箱）
4. 填写网站信息：
   - 网站网址：`https://your-domain.com`
   - 网站 language：中文
5. 填写付款信息：
   - 姓名/公司名称
   - 地址（需要接收 PIN 码验证）
   - 银行账户信息

### 步骤 3：添加验证代码

Google 会提供一段验证代码，需要添加到网站：

```html
<!-- 在 <head> 标签中添加 -->
<script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-XXXXXXXXXXXXXXXX" crossorigin="anonymous"></script>
```

**操作方法：**
1. 打开 `src/app/layout.tsx`
2. 找到 `<head>` 标签
3. 取消注释 AdSense 脚本
4. 替换 `ca-pub-XXXXXXXXXXXXXXXX` 为你的发布商 ID

### 步骤 4：等待审核

- 审核时间：通常 1-7 天
- Google 会检查网站内容、流量、用户体验等
- 审核通过后会收到邮件通知

### 步骤 5：创建广告单元

审核通过后，创建广告单元：

1. 登录 AdSense 控制台
2. 点击"广告" → "概览"
3. 点击"按广告单元"
4. 选择广告类型：
   - **展示广告**：横幅广告（推荐）
   - **信息流广告**：嵌入内容列表
   - **文章内广告**：插入文章中间
   - **多重广告**：多个广告组合

5. 设置广告名称，如：`首页底部横幅`
6. 复制生成的广告代码

## 广告位配置

### 当前网站广告位

| 位置 | 组件 | 尺寸建议 | 广告单元 ID |
|------|------|----------|-------------|
| 首页底部 | `FooterAd` | 水平横幅 (728x90 或响应式) | 需创建并替换 |
| 工具详情页 | `InContentAd` | 矩形 (300x250 或响应式) | 需创建并替换 |

### 广告单元 ID 配置

获取广告单元 ID 后，需要更新以下文件：

#### 1. 发布商 ID（全局）

文件：`src/app/layout.tsx`

```tsx
// 替换 ca-pub-XXXXXXXXXXXXXXXX 为你的发布商 ID
<script
  async
  src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-YOUR_PUBLISHER_ID"
  crossOrigin="anonymous"
/>
```

#### 2. 首页底部广告

文件：`src/components/AdSense.tsx`

```tsx
export function FooterAd({ client }: { client?: string }) {
  return (
    <div className="my-4 flex justify-center">
      <AdSense
        client={client}
        slot="YOUR_FOOTER_SLOT_ID"  // 替换为实际的广告单元 ID
        format="horizontal"
        className="w-full max-w-4xl"
        style={{ minHeight: '90px' }}
      />
    </div>
  );
}
```

#### 3. 详情页广告

文件：`src/components/AdSense.tsx`

```tsx
export function InContentAd({ client }: { client?: string }) {
  return (
    <div className="my-6 flex justify-center">
      <AdSense
        client={client}
        slot="YOUR_IN_CONTENT_SLOT_ID"  // 替换为实际的广告单元 ID
        format="rectangle"
        className="w-full"
        style={{ minHeight: '250px' }}
      />
    </div>
  );
}
```

## 代码接入

### 完整接入步骤

1. **获取 AdSense 发布商 ID**
   - 格式：`ca-pub-XXXXXXXXXXXXXXXX`
   - 在 AdSense 控制台"账户"→"账户信息"中查看

2. **创建广告单元并获取 Slot ID**
   - 在 AdSense 控制台"广告"→"按广告单元"中创建
   - 创建后复制广告代码中的 `data-ad-slot` 值

3. **更新代码**

```bash
# 编辑布局文件
src/app/layout.tsx  # 添加 AdSense 脚本

# 编辑广告组件
src/components/AdSense.tsx  # 更新 Slot ID
```

4. **测试广告显示**
   - 在 AdSense 控制台中可以预览广告效果
   - 上线后等待几小时广告才会显示
   - 新网站可能需要 1-2 周才能看到相关广告

### 开发环境测试

广告组件支持占位符模式，方便开发时查看广告位置：

```tsx
import { AdPlaceholder } from '@/components/AdSense';

// 使用占位符（不加载真实广告）
<AdPlaceholder width="100%" height="90px" label="广告位" />
```

## 优化建议

### 提高审核通过率

1. ✅ **绑定自定义域名** - 显得更专业
2. ✅ **添加必要页面** - 关于、隐私政策、联系
3. ✅ **原创内容** - 避免复制粘贴
4. ✅ **移动端适配** - 已实现响应式
5. ⏳ **积累流量** - 运营 1-2 个月后再申请

### 提高广告收益

1. **广告位置优化**
   - 首屏广告点击率最高
   - 内容中穿插广告体验好
   - 避免过多广告影响用户体验

2. **自动广告 vs 手动广告**
   - 初期建议使用自动广告
   - 熟悉后切换手动广告，控制更精准

3. **屏蔽低价值广告**
   - AdSense 控制台可以屏蔽特定类别
   - 屏蔽与内容无关的广告

4. **A/B 测试**
   - 测试不同广告位置
   - 测试不同广告尺寸
   - 分析哪些配置收益最高

## 常见问题

### Q1: 审核被拒绝怎么办？

**常见拒绝原因：**
- 网站内容不足
- 网站还在建设中
- 流量太少
- 内容违规（成人、暴力、版权问题）
- 域名太新

**解决方案：**
1. 补充更多内容
2. 运营一段时间积累流量
3. 检查是否有违规内容
4. 绑定自定义域名
5. 等待 1 个月后重新申请

### Q2: 广告不显示怎么办？

**排查步骤：**
1. 检查代码是否正确添加
2. 等待 24-48 小时生效
3. 清除浏览器缓存
4. 检查 AdSense 账户状态
5. 查看是否有政策违规警告

### Q3: 收益太低怎么办？

**优化方向：**
1. 提高网站流量
2. 优化广告位置
3. 测试不同广告格式
4. 提高内容质量，吸引高价值用户
5. 关注高单价地区用户

### Q4: 需要多少流量才能有收益？

- 最低：日 PV 500+ 可能有少量收益
- 正常：日 PV 2,000+ 才有稳定收益
- 理想：日 PV 10,000+ 收益可观

### Q5: AdSense 和其他广告平台对比？

| 平台 | 特点 | 推荐度 |
